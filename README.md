### App Overview
CampusConnect is a mobile application developed using **Flutter** and **Dart** in **Android Studio**. It is designed specifically for university students to streamline their academic tasks, manage course deadlines, and organize campus study groups.

### Core Technologies
* **Framework:** Flutter
* **Language:** Dart
* **IDE:** Android Studio
* **Backend / Database:** Firebase Authentication & Cloud Firestore
